**你有一个真正想实现的目标：转行、学一门技能、考研考证、做出一个作品、养成一个习惯。**

大多数工具只会把目标拆成一串待办，然后你对着 50 条任务发呆。思而行不这么干：它先用问卷（含客观自测）把你的**真实起点**问清楚，不清楚的地方还能逐题深挖追问；问透之后才生成「阶段 → 小目标 → 任务」三级路径，并且**随时可以继续改**。

> **目标的价值不在于被拆得多细，而在于每一步都知道自己为什么做、做到什么算数。**

## ✨ 能做什么

> [!NOTE]
> 不想看长篇介绍？直接 [30 秒上手](#-30-秒上手) 跑起来，新建一个目标，回答完问卷你就懂了。

### 先问清楚，再给路径

思而行不是"帮你把任务列出来"的清单工具。新建目标后先做问卷澄清（含客观自测）→ 加约束（每周能投入多少、期限多久）→ 确认「阶段 / 小目标 / 任务」骨架 → 逐级细化到可执行的任务。任何时候发现规划不对，用对话说一句"加一个阶段""跳过已掌握的部分"，AI 改骨架，不用推倒重来。

### 看得见全局，也落得到今天

路线图上有全屏导图看全局，也有按阶段折叠的清单；每个任务的完成态、验收标准、产出物都记在同一个地方。每天打开首页，先看到「最近目标」和「下一个任务」，而不是一百个待办。

### 让 AI 当真正的助手，而不是聊天框

规划、改规划、写教程、追问知识点、检查资料，全部走**同一套 AI 助手**（悬浮 💬 + 右侧抽屉，跨页保持）。它知道你当前在看哪个页面、哪个目标、哪些资料——因为**当前页面渲染出来的内容就是它的上下文**。组件不需要各自再实现一套"问 AI"。

## 🚀 30 秒上手

> ⚠️ **只复制代码块里的内容**，下面的中文说明粘到终端会报错。

### 方式一：下载单文件 exe（推荐给不想折腾的人）

去 <https://atomgit.com/sierxing/SiErXing/releases> 下载 **`SiErXing.exe`**，双击即可。

- **不用装 Node、不用敲命令、不需要管理员权限**，整个程序就这一个文件
- 首次运行会把程序文件解到 `%LOCALAPPDATA%\SiErXing\app`（约 2MB），你的数据存在其中的 `data\` 目录
- **以后更新不用重下 exe**：启动时自动检查，发现新版本只下载几百 KB 的程序文件替换掉旧的，89MB 的 exe 本身不用动
- 没做代码签名，Windows SmartScreen 会拦一下 → 点「更多信息」→「仍要运行」
- 双击后会自动打开浏览器；在弹出的黑色窗口里按 `Ctrl + C` 可停止服务

### 方式二：git clone（适合开发者）

**Linux / macOS**

```bash
git clone --depth 1 https://atomgit.com/sierxing/SiErXing.git ~/SiErXing && bash ~/SiErXing/scripts/install.sh
```

**Windows**（PowerShell，整行复制）

```powershell
git clone --depth 1 https://atomgit.com/sierxing/SiErXing.git "$env:USERPROFILE\SiErXing"; & "$env:USERPROFILE\SiErXing\scripts\install.bat"
```

想装到其它目录，把 `D:\SiErXing` 换成你的路径：

```powershell
$d="D:\SiErXing"; git clone --depth 1 https://atomgit.com/sierxing/SiErXing.git $d; & "$d\scripts\install.bat"
```

**手动启动**

```bash
node server/server.js          # 然后打开 http://localhost:3213
```

只需要 **Node.js ≥ 22.5**（推荐 24 LTS），**不需要 `npm install`**。
安装脚本会自动：检查 Node → 启动服务 → 建桌面图标 → 建终端命令 `sierxing` → 询问开机自启 → 打开浏览器。

### 配置 AI（唯一必须做的事）

打开 <http://localhost:3213> → 左侧栏 **⚙ 设置** → 选接入方式 → **测试连接**：

| 方式 | 填什么 |
| --- | --- |
| **OpenAI 兼容接口**（推荐） | 点预设一键填好（DeepSeek / 通义千问 / Kimi / 智谱 / OpenAI…），再填 API 密钥 |
| **本地 Ollama**（离线免费） | 地址 `http://localhost:11434/v1`，模型如 `qwen2.5:14b`，密钥随便填 |
| **opencode CLI**（已装可选） | 模型填 `provider/model`，地址密钥留空 |

配好后：**新建目标 → 回答问卷（可逐题深挖）→ 加约束 → 确认骨架 → 细化任务 → 开始执行**。第一次打开有 5 步使用引导。

## 🧩 组件：功能可以自己加

每个功能、甚至界面皮肤都是**独立文件**的组件。自己导入/创造的组件只写数据目录（`DATA_DIR/plugins` + `DATA_DIR/plugins-client`），**升级不会被覆盖**；程序目录 `server/plugins/` 是内置组件区。改完刷新即生效，不用重新安装。

内置：信息源导入 / 每日刷题 / 学习统计 / 教程书签 / 随堂测验 / 用自己的话 / 笔记面板 / 代码工作区 / 番茄钟 / 提示词库 / 主题皮肤（碳黑 · 宣纸 · 暖沙 · 护眼绿 · 雾蓝 · 夜蓝，亮色 / 暗色模式可分别选）。

**开关按目标隔离**：组件管理页顶部选「🌍 全局默认」还是某个「🎯 目标」，选目标时下面的开关只影响那一个目标，其它目标不受影响。组件的功能入口放进**该页顶栏的标签栏**里，可拖拽排序、收进收藏夹或 ⋯ 菜单。

**分享组件**：组件页点「导出」得到 `*.component.json`，对方导入即可装好。

自己写一个：新建 `server/plugins/xxx.js`（元数据 + 接口 + 建表）、`public/plugins/xxx.js`（界面）、`public/plugins/xxx.css`（样式），重启即可。接口约定见 [`AGENTS.md`](AGENTS.md)。

## 🎨 创造模式：让 AI 帮你改界面 / 加功能

AI 助手工具栏里把模式切到「创造」（🎨），直接说想要什么：

- 「把首页改成暖色卡片风，圆角大一点」→ 换肤（skin）
- 「重做设置页，把 AI 接入放最上面」→ 页面插件（ui-page）
- 「在目标页加一个「专注计时」组件，能开始/暂停」→ 功能组件（component）

AI 会先回一张「🎨 已生成」卡片（**不会自动安装**）。你可以先「查看代码」，确认后点「安装并查看」；不满意点「撤销安装」即可回到安装前。所有产物只写数据目录，升级思而行不会覆盖；页面/皮肤随时能在「界面管理」（#/ui-plugins）里停用。

安全边界：不能改内核、不能联网、不许子进程 / eval、装前快照、安装必须你点确认。细节见 [`docs/creation-mode.md`](docs/creation-mode.md)。

## 📦 数据、备份与隐私

- **数据库**：`data/sierxing.db`（SQLite 单文件）
- **自动备份**：每次改动自动备份到 `data/backups/`，保留最近 30 份
- **导出/导入**：设置页「导出全部 JSON」可导出所有目标、节点、来源、版本、教程、对话
- **上传的图片/电子书**：`data/uploads/`
- **隐私**：数据只存在本机，除调用你配置的 AI 接口外不上传任何内容
  - 信息源检索会访问百度/必应等公开页面（不用就不点）
  - 每日刷题会读取本机插件登录态并访问 leetcode.cn（不用可关）
- **API 密钥**：存在本机数据库或 `.env`，前端只显示掩码

## ❓ 常见问题

**一定要装 opencode 吗？** 不用。默认走 OpenAI 兼容接口，填地址 + 密钥 + 模型即可。

**报错 `当前 Node.js 不支持内置 SQLite`？** Node 版本太低。升级到 Node 24 LTS，或用 `npm run start:sqlite`（脚本会自动判断）。

**端口被占用？** `PORT=其他端口 node server/server.js`，默认 3213。

**数据会丢吗？** 不会自动上传到任何服务器。备份在 `data/backups/`，也可以用设置页导出 JSON。

**能商用吗？** 能，MIT 协议不要求开源你的修改，唯一要求是保留署名。

## 🌐 界面语言（中文 / English / 任意语言）

- **内置中文和英文**：设置 →「🌐 语言 Language」里一键切换；默认跟着浏览器语言走（中文浏览器用中文，其它用英文）。
- **没有你的语言？** 在设置里输入语言名（如 `日本語`、`Français`、`Türkçe`、`한국어`），
  点「AI 生成界面语言」—— 它会调用你已配置的 AI 模型，把整套界面文案翻译成该语言并保存，
  之后可以随时切回或删除（会消耗一点点 AI 调用费用，界面里有提示）。
- **界面文字全部集中在 `language/` 目录管理**：改文案不用改代码；AI 生成的语言包在数据目录里，
  升级程序不会覆盖。规则和操作手册见 [`language/README.md`](language/README.md)。
- 当前约定：只翻译**界面**；AI 生成的内容（规划、教程、对话）仍保持模型原始输出语言。

## 给开发者 / AI 助手

代码结构、组件接口、数据表、接口约定、以及**一堆踩过的坑**，都在 [`AGENTS.md`](AGENTS.md)。
想直接上手改代码，建议先读它。

```bash
node server/server.js              # 启动（默认 3213）
PORT=3214 node server/server.js    # 换端口
```

技术栈：Node 内置 `http` + `node:sqlite`，**零第三方依赖**；前端原生 JS，无构建步骤。

**文案规范（写代码前必读）**：界面文字不许写死在代码里，必须走 `tr('中文原文')` 并由
[`language/`](language/README.md) 统一管理；提示词正文放 `language/prompts/`；
自检命令 `npm run check:i18n`，规则详见 [`AGENTS.md` §0.1](AGENTS.md) 与 [`language/README.md`](language/README.md)。
